## Featured Repositories

### ms_fabric_inventory

A .NET 9 and Blazor application for inventorying Microsoft Fabric and Power BI assets.

The app focuses on collecting and organizing metadata across capacities, workspaces, datasets, reports, lakehouses, warehouses, and related Fabric resources. It is designed to help teams better understand their analytics estate, track assets, and support governance or operational reviews.

### ai_data_analyzer

A Python application built primarily with LangGraph for AI-assisted data analysis.

The app processes user questions, analyzes data stored in Microsoft Fabric, and returns a response tailored to the prompt. Depending on the request, it can generate a written summary, visualizations, and tables to help users explore and understand their data more naturally.

### dotnet

C# code snippets used in articles published on [Medium](https://medium.com/@michalmolka).

Most examples focus on the Azure ecosystem, Microsoft Fabric, and Power BI. The repository is a practical reference for developers working with cloud analytics, automation, APIs, and data platform integrations in .NET.

### python

Python examples and small PoC applications focused on data engineering and Power BI analysis.

The repository includes two simple apps: one for handling ETL workflows in pure Python, and another for gathering statistics from Power BI semantic models. These projects are intended as lightweight, practical examples for everyday analytics engineering scenarios.
